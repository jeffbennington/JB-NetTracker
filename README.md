# JB NetTracker

<img width="1082" height="528" alt="изображение" src="https://github.com/user-attachments/assets/ac1fade9-300c-4669-bc67-b95bf923a536" />

JB NetTracker is a compact utility for network monitoring under Windows.

It shows your external IP address, measures Internet speed through servers around the world, and displays ping to popular DNS servers and any IP addresses of your choice. The built-in traffic counter records data consumption from the beginning of the session in real time.
